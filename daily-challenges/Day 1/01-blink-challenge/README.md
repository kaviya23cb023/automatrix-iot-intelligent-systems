# Challenge 01 – Blink Challenge

## Objective

Blink the ESP32's built-in LED at 1-second intervals.

## Components

* ESP32 Development Board
* Built-in LED

## Platform

* Wokwi Simulator
* Arduino C++

## Wokwi Simulation

[Click here to view and run the simulation](https://wokwi.com/projects/476291089284169729)

## Source Code

The Arduino implementation is available in [sketch.ino](./sketch.ino).

## Implementation

The ESP32 controls its built-in LED by switching its GPIO output between HIGH and LOW states with a 1-second delay.
