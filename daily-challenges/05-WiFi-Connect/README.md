# Problem 5 – ESP32 WiFi Connect

## Challenge

Connect the ESP32 to a Wi-Fi network and print its assigned IP address to the Serial Monitor.

## Objective

Establish a Wi-Fi connection using the ESP32 and display the connection status, assigned IP address, and Wi-Fi signal strength.

## Components

* ESP32 development board
* Wokwi ESP32 simulator

## Software

* Arduino C++
* Wokwi Simulator

## Working

1. Initialize serial communication at 115200 baud.
2. Set the ESP32 to Wi-Fi station mode.
3. Connect to the Wokwi guest Wi-Fi network.
4. Wait until the connection is established.
5. Print the connection status, assigned IP address, and signal strength to the Serial Monitor.

## Simulation

[Run the ESP32 WiFi Connect simulation on Wokwi](https://wokwi.com/projects/476421309428907009)

## Files

* `sketch.ino` – ESP32 Wi-Fi connection program
* `diagram.json` – Wokwi circuit configuration

## Expected Output

The Serial Monitor displays the Wi-Fi connection progress, connection status, assigned IP address, and signal strength.
