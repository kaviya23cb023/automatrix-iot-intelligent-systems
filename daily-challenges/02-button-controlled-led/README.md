# Challenge 02 – Button-Controlled LED

## Objective

Control an external LED using a push button connected to the ESP32.

## Components

* ESP32 Development Board
* Push Button
* External LED
* Connecting Wires

## Platform

* Wokwi Simulator
* Arduino C++

## Wokwi Simulation

[Click here to view and run the simulation](https://wokwi.com/projects/476291179266679809)

## Source Code

The Arduino implementation is available in [sketch.ino](./sketch.ino).

## Implementation

The ESP32 reads the push-button input and controls the external LED. Software debouncing helps prevent unwanted multiple detections caused by mechanical button bouncing.
